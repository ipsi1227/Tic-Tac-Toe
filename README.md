A simple Tic-Tac-Toe game built using Python.

✨ Features
Player vs Computer
Player uses X
Computer uses O
Positions are numbered 1–9
Computer chooses moves automatically
Detects wins
Detects draws
Handles invalid inputs

▶️ How to Run
Make sure Python is installed.

Run:
python tictactoe.py

🎯 How to Play
The board shows numbers for available positions:
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
Enter the number of the position where you want to place your X.
The computer will automatically place its O.
