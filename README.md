Tic-Tac-Toe Python

A simple Tic-Tac-Toe game built using Python.

Features

-  Player vs Computer
-  Player uses X
-  Computer uses O
-  Positions are numbered 1–9
-  Computer chooses moves automatically
-  Detects wins
-  Detects draws
-  Handles invalid inputs

## How to Run

Make sure Python is installed.

Run:

```bash
python tictactoe.py
